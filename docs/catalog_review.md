## 수정 항목

- **C04** (PECVD / 가스 / E-1202): "필터 포화로 인한 파티클 오염"은 인과가 어색함 — 인라인 필터가 막히면(클로깅) 현장에서 먼저 보이는 건 필터 전후 차압 상승과 고유량 설정 시 MFC 유량 미달이지 파티클 증가가 아니며, 지금 증상("공정 압력 미세 변동")은 C03(MFC 영점 드리프트)의 "설정값-실측값 차이"와 사실상 같은 신호라 둘을 가르는 증상이 없음. 차압 상승·유량 미달 중심으로 증상을 바꾸고 C03은 "영점 보정 후 해소"로 구분.
- **C14** (ETCH / RF / E-2302): ESC 유전층 열화를 RF 서브시스템에 두고 C13(RF 케이블 피복 손상)과 confusable로 묶었지만, 실제 증상(척킹 실패, He 백사이드 누설 증가, 웨이퍼 온도 편차)은 RF 반사파·아크와 겹치지 않아 confusable 관계가 이름뿐임. 또 He 누설 증가는 유전층 열화보다 엠보싱/실링 밴드 마모 쪽 신호이므로, 서브시스템을 "척(ESC)"으로 옮기고 증상을 척킹력 저하·누설 전류 증가·디척킹 지연처럼 유전층 열화 고유 신호로 정리.

## 분리도 테스트 결과 (심판 qwen2.5:7b, --runs 3, 원본 로그 docs/experiments/separability_2026-10-26.txt)

`정확 34/40, confusable 경유 5/40, 실패 1/40` — 실패 쌍 {('C14', 'C12'): 1}

- **C14 → C12** (3표 모두): "헬륨 백사이드 누설 증가"를 심판이 가스 박스 피팅 누설(C12)로 읽음. 위 C14 수정 근거를 뒷받침 — He 백사이드 누설은 ESC 고유 신호가 아니라 "누설"이라는 단어 때문에 가스 계통으로 끌려감. 증상을 척킹력 저하·누설 전류·디척킹 지연으로 바꾸면 해소 예상.
- **C05 / C06** (1·1·1 동표): RF 매처 고착 vs 샤워헤드 오염 — 둘 다 "반사파/튜닝" 류 증상으로 겹침. confusable_with로 이미 묶여 있어 통과 처리되지만 증상 차별화 후보.
- **C35 → C34** (3표): 컨디셔너 디스크 마모 증상이 패드 글레이징과 동일하게 읽힘. confusable 경유라 통과. 의도한 난이도면 유지.
