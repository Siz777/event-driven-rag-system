## 실험 — two_stage band 3차: train 점수 분위수 (lo = 음성 99분위, hi = 양성 1분위), 모델 ft_no_confusable_e2
| | 값 |
|---|---|
| train 상위 5 쌍 | 1,090 (음성 598 · 양성 492) |
| lo = 음성 q99 | **0.9998** (q90 0.887, q95 0.998) |
| hi = 양성 q1 | **0.0207** (q5 0.757, q10 0.976) |
| 뒤집힘(hi < lo) | 예 → 애매 구간 없음, 위임 0/325 |
| 이 band로 로컬만 판정했을 때 val 오류 | 양성인데 no(≤ lo) 100/146 · 음성인데 yes(≥ hi) 51/179 |

- 왜 뒤집히나: 음성 상위(≥ 0.9) 58건 중 **55건이 confusable 쌍** — no_confusable 변형은 이웃 원인 쌍을 학습에서 뺐으므로 모델이 그것들을 양성처럼 1.0 근처로 올린다. 음성 분포의 꼬리가 1.0에 닿으니 "음성 99분위"는 곧 1.0이다. val도 같다(음성 ≥ 0.9 14건 중 confusable 10).
- 결론: 이 모델의 점수는 확률로 보정돼 있지 않다(양성 중앙값 0.995, 음성 중앙값 0.008, 그런데 이웃 원인은 1.0). 분위수든 precision이든 train 분포로 band를 잡을 수 없고, "애매함"을 재려면 (1) confusable을 라벨 0으로 넣고 보정(temperature/Platt)하거나 (2) 라벨을 API 판정 기준으로 바꿔야 한다. 11-06 1차(precision band, false no_match 0.404)·2차(lo = threshold, 위임 49%·득 없음)와 합쳐 **two_stage는 현 라벨로는 성립하지 않음**으로 닫는다. 40% 기준으로 보면 2차가 49%로 이미 초과였고 3차는 0%지만 band가 뒤집혀 의미가 없다.
